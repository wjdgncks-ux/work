# 계정 페르소나 정의

## huchan_main — 정후찬 개인 (도달 계정)

**한 줄 정체성**: 9년간 460개 기업을 붙어본 대행사 대표가, 업계가 말 안 하는 걸 말한다.

- **타겟**: 마케팅 예산을 직접 결정하는 대표·실무 총괄. 이미 한 번 이상 대행사에 데인 사람.
- **톤**: 단정형. 완충어("~인 것 같습니다", "~할 수도 있습니다") 제거. 근거는 뒤에 붙인다.
- **무기**: 실패 사례와 자기 실수. 성공담보다 "내가 틀렸던 것"이 스레드에서 훨씬 멀리 간다.
- **금지**: 다크심리학·조작 기법·"영업 비밀" 류 어그로.
  조회수는 나오지만 모이는 독자가 리테이너 계약을 결정하는 사람과 겹치지 않는다.
  또한 대행사 신뢰 자산과 정면으로 충돌한다.

**같은 자극, 다른 재료** — 어그로 대신 이걸 쓴다:
| 대신 쓰는 것 | 예시 첫 줄 |
|---|---|
| 업계 관행 폭로 | "대행사가 '상위노출 보장'이라고 쓸 때 실제로 보장하는 건 노출이 아닙니다." |
| 자기 손실 고백 | "작년에 한 클라이언트한테 400만원 돌려줬습니다. 제 판단이 틀려서요." |
| 통념 반박 | "리뷰 이벤트로 별점 올리면 매출 떨어집니다. 460개 붙어보고 내린 결론입니다." |
| 비용 공개 | "블로그 상위노출 1건 원가, 그냥 공개합니다." |

## eggglobal — 에그글로벌 브랜드 (신뢰·전환 계정)

**한 줄 정체성**: 숫자로 증명하고 방법을 알려주는 대행사.

- **타겟**: 개인 계정에서 넘어온 사람 + 검색·추천으로 들어온 사람.
- **톤**: 차분하고 구체적. 사례 → 수치 → 실행 3단 구조.
- **역할**: 문의 수납처. 프로필 링크·랜딩·상담 경로가 여기 모인다.
- **금지**: 도달을 노린 자극. 이 계정이 자극적이면 전환 기능을 잃는다.

## 두 계정의 관계 (공개 원칙)

- 두 계정이 같은 운영 주체임을 **숨기지 않는다.** 프로필에 상호 링크.
- 개인 → 브랜드로 넘기는 문장은 명시적으로: "자세한 건 에그글로벌 계정에 정리해뒀습니다."
- **가짜 대립 금지.** 대립이 필요하면 정후찬 vs 강도한 이사(실존 2인, 실제 관점 차이,
  양쪽 실명 공개) 또는 자기 반박 구조를 쓴다.

## 실존 2인 대립 운영법 (권장 포맷)

같은 주제에 두 사람이 실제로 다르게 답하는 것만 다룬다. 대본을 쓰지 않는다.

| 주제 | 정후찬(대행·현장) | 강도한(퍼포먼스) |
|---|---|---|
| 초기 예산 배분 | 검색·플레이스 기반부터 | 광고로 먼저 수요 검증 |
| 소재 제작 | 전환되는 소재는 정형화됨 | 소재는 계속 갈아엎어야 함 |
| 측정 | 문의 건수 | ROAS·CPA |

두 사람 각각의 실제 답을 받아서 쓴다. 한 사람이 양쪽을 지어내면 그 순간 사칭이다.
