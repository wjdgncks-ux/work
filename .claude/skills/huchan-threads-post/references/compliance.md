# 컴플라이언스 필터 (스레드용)

규제 업종이 주제에 닿으면 무조건 적용한다. 대행사 계정은 자기 글에도 같은 기준을 적용해야
클라이언트에게 기준을 요구할 명분이 생긴다.

## 업종별 금지

| 업종 | 금지 | 대체 표현 |
|---|---|---|
| 병원·의료 | "시술 받았다" 후기형 서술, 병원 실명 노출 | "상담 받으러 갔다" |
| 병원·의료 | 치료 효과 단정("완치", "100% 개선") | "개인차가 있습니다" 병기 |
| 화장품 | 의약품 오인 표현("재생", "치료") | 기능성 고시 문구 범위 내 |
| 건기식 | 질병 예방·치료 표현 | 인정받은 기능성 문구만 |
| 전 업종 | "국내 최초", "1위" (객관적 근거 없이) | 근거 출처 병기 또는 삭제 |

## 표시·광고 표기

- 대가성이 있으면 `#광고` `#협찬` 을 **본문 첫 줄에 별도 표기**한다.
  해시태그 목록에 섞으면 표기로 인정되지 않는다.
- 자사 홍보 게시물은 표기 대상이 아니지만, 제휴·수수료 구조가 있으면 표기한다.

## 판단 불가 시

법 조항을 추측하지 않는다. 초안에 다음을 남긴다:

```
[법령 확인 필요] 해당 표현의 근거 조항을 국가법령정보센터(https://www.law.go.kr)에서 확인할 것
```

## 계정 운영 컴플라이언스

- **복수 계정으로 독립 당사자 연출 금지** — Meta Inauthentic Behavior 정책
  (https://transparency.meta.com/policies/community-standards/inauthentic-behavior/)
- 자동 발행은 검수를 통과한 초안만. 24시간 250건(게시물) / 1,000건(답글) 쿼터 내에서 운용
  (https://developers.facebook.com/documentation/threads/overview)
- 타인 게시물 텍스트를 그대로 옮기지 않는다. 구조만 참고하고 재작성한다.
