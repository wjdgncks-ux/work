# 인스타 계정 운영 대시보드 (구글 시트 + Apps Script)

여러 인스타그램 계정의 성과를 매일 자동으로 모으고, 콘텐츠 기획과 협찬 관리까지 한 시트에서 운영하기 위한 도구입니다.

- 시트: [인스타 계정 운영 대시보드](https://docs.google.com/spreadsheets/d/1sYkWOZsbZeuH_2dGi-9d52g4R0UCQF7QtpgnFyFOt0E/edit)
- 자동 수집 코드: [`Code.gs`](./Code.gs)

## 탭 구성

| 탭 | 용도 | 갱신 |
|---|---|---|
| 대시보드 | 계정 선택 → KPI, 일별 도달 추이, 자동 진단, 공유율·조회 TOP5, 다가오는 기획, 팔로워 구성 | 수식 |
| 콘텐츠기획 | 시리즈·회차·훅 자막·포맷·목적·상태. 게시 후 **L열에 링크**를 넣으면 결과 조회·공유율이 자동 연결 | 수동 |
| 협찬관리 | 브랜드·유형·원고료·광고표시·계약·정산. 링크 입력 시 성과 자동 연결 | 수동 |
| 콘텐츠성과 | 게시물별 조회·도달·좋아요·댓글·공유·저장·평균시청·비율 | 자동 |
| 일별지표 | 날짜별 도달·조회·프로필방문·신규팔로우·상호작용·공유·저장 | 자동 |
| 팔로워구성 | 연령·성별·국가·도시 (팔로워 100명 이상 계정만 제공) | 자동 |
| 계정 | 수집 대상 계정 목록, 토큰 키 이름, 수집 ON/OFF | 자동 + 수동 |

## 1. 자동 수집 설치 (최초 1회, 약 5분)

1. 시트 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
2. 기본 `Code.gs` 내용을 지우고 이 폴더의 [`Code.gs`](./Code.gs) 전체를 붙여넣은 뒤 저장합니다.
3. 왼쪽 **⚙ 프로젝트 설정 → 스크립트 속성 → 속성 추가**
   - 속성: `TOKEN_JJONDEUK`
   - 값: Meta 시스템 사용자 토큰 (비즈니스 설정 → 시스템 사용자 → claude-analytics → 토큰 생성)
4. 시트를 새로고침하면 상단에 **📊 인스타 수집** 메뉴가 생깁니다.
   **지금 수집 실행**을 눌러 Google 권한을 승인합니다.
   ("확인되지 않은 앱" 경고가 나오면 고급 → 이동. 본인이 만든 스크립트라 정상입니다.)
5. **매일 자동 수집 켜기 (오전 6시)**를 누릅니다.

> 토큰은 시트 셀이 아니라 스크립트 속성에만 저장됩니다. 시트를 공유해도 토큰은 보이지 않습니다.
> 단, 시트 **편집 권한**을 받은 사람은 Apps Script를 열 수 있으므로 편집 권한은 가족에게만 주세요.

## 2. 계정 추가

### 개인 계정
1. 인스타 앱에서 **프로페셔널(크리에이터) 계정**으로 전환합니다.
2. 비즈니스 설정(쫀득이계정 관리) → **Instagram 계정 → 추가**
3. 시스템 사용자 `claude-analytics` → **자산 할당**에 그 계정 추가
4. `계정` 탭에 핸들과 IG 계정 ID 입력, 토큰 키 `TOKEN_JJONDEUK`, 수집 `ON`
   (IG 계정 ID는 비즈니스 설정 → Instagram 계정에서 계정을 누르면 `ID: 1784...`로 표시됩니다.)

### 회사 계정 (EggGlobal, b.p.m_inc)
회사 자산은 회사 포트폴리오 안에서 분리 관리합니다.
1. 해당 회사 포트폴리오에 Instagram 계정이 등록되어 있는지 확인합니다.
2. developers.facebook.com에서 **그 회사 포트폴리오 소속으로 앱을 하나 생성**합니다.
3. 회사 포트폴리오 → 시스템 사용자 생성(직원) → 앱 + Instagram 계정 자산 할당 → 토큰 생성
   - 권한: `instagram_basic`, `instagram_manage_insights` (+ 목록에 있으면 `pages_show_list`, `pages_read_engagement`)
4. Apps Script 스크립트 속성에 `TOKEN_EGGGLOBAL` / `TOKEN_BPM`으로 저장합니다.
5. `계정` 탭 해당 행에 핸들·IG 계정 ID 입력 → 수집 `ON`

> 회사 계정 데이터를 개인 시트로 가져오는 것은 **회사 정보 반출**에 해당할 수 있습니다. 대표/관리자 승인을 먼저 받으세요.

## 3. 운영 루틴

| 주기 | 할 일 |
|---|---|
| 매일 (자동) | 06:00 수집. `계정` 탭 메모 열에 `정상 수집` / `오류: …` 표시 |
| 게시 직후 | `콘텐츠기획` 상태를 `게시완료`로 바꾸고 L열에 게시 링크 붙여넣기 |
| 매주 1회 | 대시보드 진단 확인 → 다음 주 기획 6개 작성 (Claude에게 "주간 분석" 요청 가능) |
| 협찬 시 | `협찬관리`에 행 추가. 광고 표시는 **유료 파트너십 라벨** 권장 |
| 토큰 만료 전 | 시스템 사용자 토큰 재발급 → 스크립트 속성 값만 교체 |

## 지표 정의

- **프로필 방문률** = 프로필 방문 ÷ 도달. 영상이 계정 자체에 대한 관심으로 이어지는지 보는 병목 지표 (목표 1%)
- **방문→팔로우 전환** = 신규 팔로우 ÷ 프로필 방문. 프로필이 팔로우 이유를 주는지
- **공유율 / 저장율 / 좋아요율** = 각 수치 ÷ 도달
- **28일 도달(일별 합)** = 일별 도달의 합계. 고유 도달(인스타 앱의 28일 도달)보다 크게 나옵니다
- **릴스 조회 중앙값(최근 10)** = 협찬 제안서에 쓰는 기준선. 바이럴 최고치 대신 이 값을 사용
