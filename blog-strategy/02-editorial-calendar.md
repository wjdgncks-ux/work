## 발행 전 반드시 처리할 것

1. **키워드 검색량 실측** — 24편 제목의 핵심 키워드를 네이버 검색광고 키워드도구(https://searchad.naver.com)에서 전수 확인. 검색량 0이면 제목을 교체한다. 이 계획서의 검색 의도는 **가설이지 실측값이 아니다.**
2. **노출 영역 확인** — 해당 키워드 검색 시 블로그 영역이 실제로 노출되는지 확인한다. 플레이스·지식iN만 나오는 키워드는 블로그로 잡을 수 없다.
3. **사례 사용 동의** — 11번(집밥김사장), 8번(UNMOOD)은 자사 사업이라 문제없으나, 클라이언트 사례를 쓸 경우 **서면 동의를 먼저 받는다.** 마스터 소스 5장 클라이언트 실명은 내부 학습용이므로 외부 발행 시 전부 익명 처리.
4. **법 조문 재확인** — 5·7·12·16·22번은 법령 인용 글이다. 발행 직전 국가법령정보센터(https://www.law.go.kr)와 공정거래위원회(https://www.ftc.go.kr)에서 현행 조문을 확인한다. 분기 1회 재검토.
5. **콘텐츠 재활용 경로 확정** — 각 글은 발행 후 릴스 1편 + 인스타 카드 1장으로 파생시킨다 (교안 6-2장 ④).
