## 한 문장 요약

> 에그글로벌 블로그는 포트폴리오 전시장이 아니라 **사장님 자가진단 도구**다.
> 1차 역할은 신규 유입이 아니라 **아웃바운드 리드의 신뢰 검증**이며,
> 교안을 공개할수록 "이 회사는 안다"와 "혼자서는 못 한다"가 동시에 증명된다.

## 착수 전 선결 과제 4개

1. 블로그 현재 상태 실사 (카테고리 · 최근 5편 · 발행 공백 · 이웃 수) → 성숙도 판정
2. 24편 제목 키워드 검색량 전수 실측 (네이버 키워드도구)
3. 리드마그넷 3종(LM-1/2/3) 실물 제작 + 구글폼 세팅
4. 유료 진단(G2) 가격 확정 — 객단가·기여이익률 확인 후

## 원칙

- 목표 수치를 지어내지 않는다. 3개월 실측 후 기준선을 확정한다
- `[원리]` / `[경험칙]` / `[검증필요]` 3단계 라벨링을 유지한다
- `[검증필요]` 수치는 공개 채널에 쓰지 않는다 (회수 불가)
- 법 조문은 분기 1회 국가법령정보센터에서 재확인한다
