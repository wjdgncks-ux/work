# 고객 확보 퍼널 설계

교안 9장(퍼널 설계)·10-4장(허용 CAC)·12-3장(수수료)을 에그글로벌 **자사 고객 확보**에 적용한 설계서.

---

## 1장. 전체 퍼널 구조

```
[발견]  아이보스 쪽지·댓글 / 이메일 아웃바운드 / 네이버 검색(블로그) / 인스타 릴스
            │
            ▼
[검증]  네이버 블로그  ← 실증형·컴플라이언스형·내부공개형 글 + 대표 프로필
            │                                    ★ 이 채널의 본진
            ▼
[리드]  리드마그넷 3종 → 구글폼 제출              ← 유일한 착지점
            │
            ▼
[진단]  유료 기본진단 리포트 (트립와이어)          ← 플레이스 25항목 100점 환산
            │
            ▼
[전환]  12주 실행 계약 (대행형 or 미션 부여형)
            │
            ▼
[유지]  월간 리포트 + 대표 직접 리포트 작성 미션    ← 교안 12-2장
```

**착지점은 하나로 특정한다.** 글마다 CTA가 3개면 아무도 누르지 않는다 (교안 8-4장).

## 2장. 리드마그넷 3종

교안 9-2장 원칙: **리드마그넷은 DM 키워드 또는 폼과 세트로 설계한다.**
마스터 소스 6장 4번 원칙: **"댓글 유도"가 아니라 "구글폼 신청을 통한 고가치 자료 발송"으로 실질적 DB를 수집한다.**

| ID | 자료명 | 원천 자산 | 연결 필러 | 대상 |
|---|---|---|---|---|
| **LM-1** | 네이버 플레이스 자가진단 시트 (25항목 · 100점 환산) | 플레이스 진단 체계 `diagnostic-items.md` | F1, F4 | P2 |
| **LM-2** | 업종별 광고 표현 체크리스트 (병원·건강서비스·식품·화장품·학원) | 교안 11장 + 마스터 소스 3장 | F2 | P1, P2 |
| **LM-3** | 매장 마케팅 12주 로드맵 템플릿 (미션 완료 판정 기준 포함) | 교안 12-2장 | F3, F5 | P2, P3 |

### 2-1. 왜 "자가진단 시트"가 최우선인가

- 받는 순간 **자기 점수를 알게 된다.** 60점짜리 매장은 그 자리에서 문제를 인정한다
- 인정한 상태의 리드는 **품질이 높다** (교안 8-4장, DM 키워드가 강한 이유와 동일한 원리)
- 자동 채점이 가능하다 → 사람 리소스 0으로 1차 스크리닝

### 2-2. 폼 수집 항목 (교안 1-1장 필수정보 12개에서 발췌)

필수 5개만 받는다. 항목이 많으면 제출률이 떨어진다.

| # | 항목 | 용도 |
|---|---|---|
| 1 | 업종 / 세부업종 | 컴플라이언스 필터 라우팅 |
| 2 | 지역 (동·역 단위) | 키워드 설계 기준 |
| 3 | 채널 URL (플레이스 / 블로그 / 인스타 중 보유분) | **실사 가능 여부 = 진단 가능 여부** |
| 4 | 월 매출 규모 (구간 선택) | 허용 CAC 산출 · 리드 등급 분류 |
| 5 | 연락처 (카톡 or 전화) | 후속 응대 |

선택 항목: 현재 광고 집행 여부, 콘텐츠 제작 인력, 가장 답답한 것 1문장

## 3장. 유료 진단 — "무상 진단"을 폐기하는 제안

### 3-1. 현재 구조의 문제

세일즈 마스터 소스 4-1 / 4-2 / 4-3, **세 템플릿 전부가 CTA를 "무상 진단"으로 쓰고 있다.**

| 문제 | 내용 |
|---|---|
| 가격 앵커 붕괴 | 9년·460개사 실적을 가진 회사가 진단을 0원에 준다 = 진단의 시장가를 스스로 0으로 고정 |
| 리소스 누수 | 진단 1건 = 채널 실사 + 25항목 판정 + 리포트 작성. 전환되지 않는 리드에도 동일 투입 |
| 리드 품질 저하 | 0원이면 "일단 받아보자"가 섞인다. 진지한 리드와 구분이 안 된다 |
| 협상력 손실 | 이미 다 받아본 고객은 제안 단계에서 가격을 깎는다 |

### 3-2. 대안 — 3단 게이트

| 단계 | 상품 | 가격 | 투입 | 목적 |
|---|---|---|---|---|
| **G1 무료** | 자가진단 시트 (LM-1~3) | 0원 | **0** (자동 발송) | DB 수집 · 자기 문제 인정 |
| **G2 유료** | 기본 진단 리포트 (25항목 100점 + 우선순위 3개) | 유료 · 저가 | 반나절 | 리드 검증 · 신뢰 획득 |
| **G3 계약** | 12주 실행 (대행형 / 미션 부여형) | 월 정액 + 성과 수수료 | 상시 | 매출 |

**G2 가격은 이 문서에서 정하지 않는다.** 교안 10-4장 원칙에 따라 객단가·기여이익률·재구매 주기를 확인하지 않고 요율·가격을 제시하지 않는다. 다만 **"G2 결제 시 G3 계약 체결하면 G2 금액 전액 차감"** 구조를 권장한다 — 매몰비용 효과를 합법적으로 쓰면서, 고객 입장에서는 손해가 0이다.

### 3-3. 이 제안의 리스크 (반드시 인지할 것)

- **단기 리드 수는 확실히 줄어든다.** 무료였던 것을 유료로 바꾸면 상단 퍼널이 좁아진다
- 아이보스처럼 **가격 경쟁이 심한 채널에서는 무상 진단이 여전히 유효한 훅**일 수 있다
- → **채널별로 분리 적용**한다: 아이보스 아웃바운드는 무상 진단 유지, 블로그 인바운드는 G1→G2 유료 게이트 적용. 3개월 뒤 두 경로의 **계약 전환율**을 비교해 판단한다

## 4장. 측정 설계

### 4-1. 원칙 — 숫자를 지어내지 않는다

이 문서는 **"유입 N명, 전환율 N%" 같은 목표 수치를 제시하지 않는다.**
교안 0-2장 원칙 ④와 11-1장(출처 없는 수치를 단정하지 않는다)을 자사 계획에도 동일 적용한다.
목표치는 **3개월 실측 후 기준선을 확정하고 나서** 설정한다.

### 4-2. 주간 기록 지표 (같은 요일에 기록)

| 구간 | 지표 |
|---|---|
| 유입 | 블로그 총 조회수 · 검색 유입 수 · 유입 키워드 top 10 · 편당 조회수 |
| 리드 | 폼 제출 수 · 리드마그넷별 제출 수 · 제출 리드의 업종·지역 분포 |
| 진단 | G2 유료 진단 결제 수 · 결제 전환율(폼→G2) |
| 계약 | G3 계약 수 · 계약 전환율(G2→G3) · 평균 계약 금액 |
| 검증 트랙 | **아웃바운드 제안 → 계약 전환율** (블로그 시행 전후 비교) |

### 4-3. 블로그 ROI가 항상 과소 측정되는 문제 ⚠️

`[경험칙]` 교안 9-3장대로 "어떻게 알고 오셨어요?"를 기록해도, 블로그는 구조적으로 **실제 기여보다 낮게 측정된다.**

- 고객은 아이보스 쪽지를 받고 → 회사명을 검색하고 → 블로그를 읽고 → 답장한다
- 이때 고객이 기억하는 출처는 **"아이보스"**다. 블로그는 기록에 남지 않는다
- 즉 블로그는 **전환을 완성시키지만 크레딧을 못 받는 채널**이다

**대응**: 블로그를 귀속(attribution) 지표만으로 평가하지 않는다. 아래 두 지표를 병행한다.

| 대리 지표 | 측정 방법 |
|---|---|
| 아웃바운드 제안 → 계약 전환율의 변화 | 블로그 시행 전 3개월 vs 시행 후 3개월 비교 |
| 첫 상담에서 회사 신뢰를 묻는 질문 빈도 | 상담 기록에 체크 항목 1개 추가 |

**이 항목이 이 문서에서 가장 중요한 경고다.** 귀속 데이터만 보면 블로그는 "성과 없음"으로 나오고, 데이터 기반으로 판단하는 사람일수록 6개월 차에 블로그를 접게 된다.

## 5장. 채널 분리 원칙

| 채널 | 담당 고객군 | 담당 축 | 콘텐츠 |
|---|---|---|---|
| 네이버 블로그 | 지역 오프라인 매장 (P1·P2·P3) | 대표 + 실무/바이럴팀 | 교안 기반 5대 필러 |
| 아이보스 · 이메일 아웃바운드 | 이커머스·브랜드 퍼포먼스 | 강도한 이사 | 마스터 소스 4장 템플릿 |
| 인스타그램 | 블로그 파생 (재활용) | 실무팀 | 블로그 글 → 릴스·카드 |

**네이버 블로그에 퍼포먼스 마케팅 글을 섞지 않는다.** 주제 일관성이 깨지고, 도달 대상도 아니다.

## 6장. 실행 체제

### 6-1. 역할 분담

| 역할 | 담당 | 주당 투입 |
|---|---|---|
| 주제 확정 · 키워드 실측 | 대표 | 1시간 (2편 분) |
| 초안 작성 | 실무팀 (교안 기반) | 3~4시간 |
| 검수 (5-5장 체크리스트 10항목) | 대표 | 1시간 |
| 발행 · 파생 콘텐츠 | 실무팀 | 2시간 |

`[경험칙]` **작성보다 검수가 병목이다.** 대표 검수 시간이 주 1시간 확보되지 않으면 이 계획은 4주 차에 멈춘다.

### 6-2. 중단 방지 장치

교안 12-3장(미션 부여형)을 **자사에 그대로 적용**한다.

| 항목 | 규칙 |
|---|---|
| 완료 판정 | 발행 URL로 확인. "썼다/안 썼다"가 다투어지면 제도가 무너진다 |
| 버퍼 | 착수 전 **4편(2주치)을 미리 확보**하고 시작한다. 버퍼 없이 시작하면 첫 번째 바쁜 주에 끊긴다 |
| 최소 기준 | 바쁜 주에는 주 1회로 줄이되 **0회는 금지**. 3개월 공백은 자사 진단 기준으로 "사실상 미운영"이다 |
| 평가 시점 | **6개월 전에는 성과로 판단하지 않는다.** 착수 전 서면으로 합의한다 |
