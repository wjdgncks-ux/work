## 1장. 전제 — 대행사 자사 블로그가 실패하는 3가지 이유

교안 0-3장이 매장 사장님에게 반대하는 통념이 있듯, 대행사 자사 블로그에도 같은 수준의 통념이 있다.

| ❌ 통념 | 실제 |
|---|---|
| "대행사 블로그는 포트폴리오 전시장이다" | 성공사례만 나열된 글은 검색 수요가 없다. 검색하는 사람은 *자기 문제*를 검색하지 *남의 성과*를 검색하지 않는다 |
| "우리 노하우를 공개하면 고객을 잃는다" | 교안 12-1장 최우선 항목 5개가 전부 **비용 0**이다. 정보가 진입장벽이 아니라는 것을 회사 스스로 증명했다. 상품은 정보가 아니라 **실행과 검수**다 |
| "마케팅대행사 키워드에서 상위를 잡으면 된다" | 해당 키워드군은 대형 대행사와 어뷰징 블로그가 점령한 레드오션. 교안 3-4장 논리 그대로 — **"그 키워드에 우리가 노출되는 영역인가"를 먼저 확인**해야 한다 |

### 1-1. 핵심 판단

> **에그글로벌 블로그의 1차 역할은 "발견"이 아니라 "검증"이다.**

교안 2-1장의 4단 퍼널을 자사에 적용하면:

```
① 발견   "이런 대행사가 있네"     ← 아이보스 · 쪽지/메일 아웃바운드 · 인스타 릴스
② 검증   "여기 맡겨도 되나?"      ← 네이버 블로그  ★ 이 채널의 본진
③ 결정   "여기로 하자"            ← 진단 리포트 · 상담
④ 행동   계약                      ← 계약서 · 착수금
```

대행사 선정은 검색보다 **레퍼런스·비교검증**에서 갈린다. 아이보스 쪽지를 받은 광고주가 가장 먼저 하는 행동은 "이 회사 이름 검색"이다. 그때 나오는 것이 블로그다. 즉 **블로그의 즉각적 ROI는 신규 유입이 아니라 기존 아웃바운드의 답장률·계약 전환율 상승**으로 먼저 나타난다.

**단, 검증 채널로만 두면 신규 리드는 0이다.** 그래서 2트랙으로 간다.

| 트랙 | 목적 | 비중 | 성과 확인 시점 |
|---|---|---|---|
| **A. 검증 트랙** | 아웃바운드로 들어온 리드가 회사를 검색했을 때 신뢰를 완성 | 40% (10편) | 즉시 (제안→계약 전환율) |
| **B. 유입 트랙** | 매장 사장님의 문제 해결형 검색어를 잡아 신규 리드 생성 | 60% (14편) | 3~6개월 |

## 2장. 타겟 확정 — 한 채널에 두 고객을 태우지 않는다

에그글로벌에는 성격이 다른 두 고객군이 있다.

| | ① 지역 오프라인 매장 | ② 이커머스·브랜드 퍼포먼스 |
|---|---|---|
| 담당 축 | 정후찬 대표 + 실무/바이럴팀 | 강도한 이사 |
| 검색 행동 | **네이버**에서 검색한다 | 구글 · 아이보스 · 브런치에서 검색한다 |
| 자산 보유 | 교안 v1.0 (13장) · 플레이스 25항목 체계 | 포트폴리오 7건 (상당수 블라인드 처리) |
| 블로그 적합도 | **높음** | 낮음 |

### 결론
**네이버 블로그는 ①에만 쓴다.** ②는 아이보스·이메일 아웃바운드로 분리한다.

**근거 3개**
1. `[원리]` 네이버 블로그 검색 노출은 C-Rank 등 **주제별 전문성** 축을 포함한다. 매장 마케팅과 퍼포먼스 마케팅 글을 한 블로그에 섞으면 주제 일관성이 흐려진다. (네이버 서치어드바이저 검색 알고리즘 안내: https://searchadvisor.naver.com )
2. 퍼포먼스 마케팅 담당자는 네이버 블로그에서 정보를 찾지 않는다. 도달 자체가 안 된다.
3. 강도한 이사 관련 수치 상당수가 **블라인드 처리 또는 [검증필요]** 상태다. 공개 채널에서 쓸 수 있는 소재가 부족하다. (마스터 소스 2-2장)

## 3장. 포지셔닝 — 한 문장

> **"이론이 아니라, 매장을 직접 운영해본 사람이 법 지키면서 만드는 마케팅."**

이 문장은 검증된 3개 자산에만 기댄다.

| 자산 | 검증 상태 | 블로그에서의 역할 |
|---|---|---|
| 실사업 운영 이력 — 카페 UNMOOD 운영 후 매각(누적 6억, 2026.04.01), 집밥김사장 인수 후 매출 30%↑(월 3,000만원대) | 실사업 실적 | **"이론만 아는 대행사"와의 1차 구분선.** 반권위 소구 |
| 컴플라이언스 실무 — 의료법 제56조 2항, 공정위 추천·보증 심사지침, 네이버 리뷰 정책 개편 대응 | 법령 원문 확인 완료 | **2차 구분선.** 교안 0-2장 원칙 ⑤ "컴플라이언스가 영업 무기" |
| 9년 / 460개사 / 2,900건 / 환불률 0.1% 미만 | 사내 집계 | 숫자 권위. 단, 과다 반복 금지 |

**금지**: `[검증필요]` 태그 수치(300억 집행, 100개사 총괄, CAC 60% 절감 등)는 블로그 어디에도 쓰지 않는다. 공개 채널은 회수가 불가능하다.

## 4장. 콘텐츠 5대 필러

| # | 필러 | 정의 | 비중 | 퍼널 역할 |
|---|---|---|---|---|
| **F1** | **자가진단형** | 사장님이 지금 당장 자기 채널을 확인하게 만드는 글 | 30% | 유입 + 리드 |
| **F2** | **컴플라이언스형** | 업종별 규제·플랫폼 정책을 원문 근거로 정리 | 25% | 유입 + 검증 |
| **F3** | **실증형** | 자사 실사업·클라이언트 케이스의 과정과 숫자 | 20% | 검증 |
| **F4** | **통설 반박형** | 업계에 돌아다니는 틀린 상식을 근거로 반박 | 15% | 유입 + 검증 |
| **F5** | **내부공개형** | 에그글로벌이 실제로 어떻게 일하는가 (검수·환불·A/S 규칙) | 10% | 검증 + 결정 |

### 4-1. F5가 가장 강한 무기인 이유

대행사 블로그에서 **환불 계산식, A/S 불가 조건, 컴플라이언스 권고를 고객이 거부했을 때의 처리 원칙**을 공개하는 곳은 거의 없다. 마스터 소스 5장에 이미 실제 케이스가 있다.

- 환불: 노출일수 기준 **일할 계산** (20만원/24일 → 8,000원 환불, 20만원/4일 → 168,000원 환불)
- 병원 체험단: 시술 후기 불가 / 상담 후기만 가능, 병원명·플레이스 삽입 불가, **신고 삭제 시 A/S 불가 사전 고지**
- 공정위 문구: 해시태그 목록이 아닌 **캡션 본문 첫 줄**에 별도 표기

`[경험칙]` P3(대행사에 데인 광고주)는 성과 약속이 아니라 **불리한 조건을 먼저 말하는 태도**에서 신뢰를 판단한다. 환불률 0.1% 미만이라는 숫자보다, 환불 계산식을 공개하는 행위가 그 숫자의 증거가 된다.

## 5장. 글 작성 표준

### 5-1. 제목 공식 (교안 4-2장 그대로 적용)

```
[실제 검색어] + [구체적 이득 또는 반전]
```

| ❌ | ✅ |
|---|---|
| `[에그글로벌] 플레이스 상위노출 성공사례` | `플레이스 순위가 안 오를 때 점검 순서 6단계, 광고 늘리기 전에 확인할 것` |
| `병원 블로그 마케팅의 중요성` | `병원 블로그에 "시술 후기"를 쓰면 안 되는 이유 (의료법 제56조 기준)` |

**규칙**
- 제목 맨 앞 대괄호에 브랜드명·업종 키워드를 넣지 않는다 (클릭률을 깎고 실제 검색어와 어긋난다)
- 발행 전 **네이버 키워드도구에서 검색량 실측**. 검색량 0 키워드는 제목에서 뺀다
- 최상급·단정 표현 금지 (표시·광고의 공정화에 관한 법률)

### 5-2. 본문 구조 (교안 4-3장 변형 — B2B용)

```
1. 증상 도입    "이런 상태면 이 글이 맞습니다"     ← 자가진단 질문 1개로 시작
2. 원인 진단    왜 그렇게 되는가                    ← 근거·법령·플랫폼 정책 원문
3. 실패 원인    그동안 왜 안 됐는가                 ★ 차별화의 전부
4. 적용         구체적으로 무엇을 어떻게 바꾸는가   ← 표·체크리스트·Before/After
5. 마무리       적용 조건 + 실패 시나리오 + CTA     ← 교안 8-5장 공식
```

**3번이 이 구조의 전부다.** 대다수 대행사 블로그는 1·2·4만 쓴다.

### 5-3. 마무리 공식 (교안 8-5장) — 정보를 완결시키지 않는다

```
[정보 제공]
+ "다만 이건 ○○일 때 얘기입니다"           ← 적용 조건
+ "○○가 원인이면 오히려 역효과입니다"        ← 실패 시나리오
+ "그래서 저희는 ○○부터 확인합니다"          ← 진단의 상품화
+ [CTA — 리드마그넷 1개]
```

```

□ 최상급·단정 표현(최고·1위·완치·100% 보장)이 없는가
□ 인용한 법 조문의 원문을 law.go.kr에서 확인했는가
□ [원리]/[경험칙] 라벨이 붙어 있는가
□ 마무리에 적용 조건 + 실패 시나리오가 있는가
□ 리드마그넷 CTA가 1개로 특정되어 있는가 ("문의주세요" ❌)
□ 클라이언트 실명·업체명이 동의 없이 노출되지 않았는가
```
