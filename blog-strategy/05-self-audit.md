# 자사 블로그 실사 입력 시트

교안 1-2장(채널 실사 체크리스트) · 1-3장(성숙도 4단계 판정)을 **에그글로벌 자사 블로그**에 적용하기 위한 입력 양식.
이 시트가 채워져야 `02-editorial-calendar.md`의 24편 순서를 확정할 수 있다.

> **현재 상태: 미확보.** 세션 네트워크 정책상 `blog.naver.com` 접근 불가(브라우저 클라이언트 포함 전 경로 403).
> 아래는 캡처 또는 텍스트로 수급한다.

---

## A. 최소 입력 5개 (이것만 있으면 판정 가능)

| # | 항목 | 수급 방법 | 무엇을 판정하는가 |
|---|---|---|---|
| A1 | **마지막 발행일** | 블로그 첫 화면 | **3개월 이상 공백 = 1단계(방치) 확정** |
| A2 | **최근 10편 제목** | 목록 화면 캡처 | 검색어 대응 여부 / 필러 편중 / 제목 공식 위반 |
| A3 | **카테고리 구성** | 좌측 카테고리 영역 | 주제 일관성. 매장마케팅·퍼포먼스 혼재 여부 |
| A4 | **프로필 소개글 전문** | 프로필 영역 | 포지셔닝 일치 여부 / `[검증필요]` 수치 노출 여부 |
| A5 | **이웃·서로이웃 수** | 프로필 영역 | 기존 도달 기반 규모 |

## B. 추가 입력 (있으면 정밀도 상승)

| # | 항목 | 수급 방법 |
|---|---|---|
| B1 | 최근 3개월 유입 키워드 top 20 | 블로그 통계 > 유입분석 |
| B2 | 최근 3개월 일평균 조회수 추이 | 블로그 통계 |
| B3 | 편당 평균 체류시간 | 블로그 통계 |
| B4 | 최근 5편 본문 전문 1편 | 캡처 또는 텍스트 |
| B5 | 현재 CTA 문구·링크 구성 | 본문 하단 캡처 |

---

## C. 판정 로직 (입력되면 자동 적용)

### C-1. 성숙도 판정 (교안 1-3장)

| 조건 | 판정 | 착수 지점 |
|---|---|---|
| 블로그 없음 / 글 0~3편 | **0단계 무채널** | 카테고리 설계 → 프로필 → 첫 4편 버퍼 |
| A1이 3개월 이상 전 | **1단계 방치** | 프로필·카테고리 정비 → 주 2회 리듬 회복부터 |
| 발행은 되나 A2가 검색어 대응 없음 / CTA 없음 | **2단계 구조 부재** | 필러 재배분 → 리드마그넷 연결 → 측정 도입 |
| 검색 유입 + CTA + 측정 존재 | **3단계 구조 있음** | 유료 게이트(G2) 도입 + 광고 확장 |

### C-2. 단계별 24편 재배열 원칙

| 판정 | 캘린더 조정 |
|---|---|
| **0~1단계** | Phase 1을 F1 자가진단형으로 더 채운다. 검색 유입이 0인 상태에서 F5(내부공개형)는 읽을 사람이 없다 → F5를 W10 이후로 미룬다 |
| **2단계** | 계획 원안 유지. 기존 글 중 조회수 상위 5편을 **역순으로 리라이팅**(제목 공식 + 마무리 공식 적용)하는 작업을 W1~2에 끼워넣는다 |
| **3단계** | 신규 발행보다 **기존 유입 글에 리드마그넷 CTA를 다는 작업**이 우선. 순서를 역전시킨다 |

### C-3. 제목 감사 기준 (A2 입력 시 전수 적용)

| 판정 항목 | 실패 신호 |
|---|---|
| 맨 앞 대괄호 | `[에그글로벌]`·`[블로그마케팅]` 등으로 시작 → 클릭률 손실 |
| 실제 검색어 포함 | 검색량 0 또는 사내 용어 → 유입 불가 |
| 브랜드 표기 통일 | `에그글로벌`/`에그 글로벌`/`EGG` 혼재 |
| 구체적 이득·반전 | "~의 중요성", "~란?" 류 → 검색 의도 미충족 |
| 최상급·단정 표현 | 최고·1위·완치·100% 보장 → 표시광고법 리스크 |

### C-4. 프로필 감사 기준 (A4 입력 시)

| 판정 항목 | 기준 |
|---|---|
| 포지셔닝 일치 | "이론이 아니라 매장을 직접 운영해본 사람이 법 지키면서 만드는 마케팅"과 정합한가 |
| 실증 자산 노출 | UNMOOD 매각 / 집밥김사장 매출 30%↑가 드러나는가 |
| 금지 수치 | `[검증필요]` 항목(300억 집행·100개사 총괄·CAC 60% 절감 등) 노출 여부 → **즉시 삭제 대상** |
| 착지점 | 폼·상담 링크가 1개로 특정되어 있는가 |
