# 릴스 시나리오 10선

형식: 후킹(0~3s) → 본문 → CTA. 괄호 안 [ ]는 실제 촬영 전 확인·교체할 값.
**수치는 전부 [검증필요]** — 게시 전 출처 원문으로 교체한다.

---

## P1. 돈 정보 (유입)

### S1. "출산 전에 신청 안 하면 못 받는 돈 [N]가지" — 22초
| 시간 | 화면 | 자막/내레이션 |
|---|---|---|
| 0~3s | 얼굴 + 손가락 숫자, 손에 산모수첩 | "출산 전에 신청 안 하면 못 받는 돈 [N]가지" |
| 3~16s | 탑뷰 필기, 배속. 항목당 1.5초 | 항목명 + 금액 + **신청 기한** (기한이 핵심 — 벤치마크는 금액만 강조) |
| 16~19s | 신청 화면 캡처(복지로) | "기한 지나면 소급 안 되는 것도 있어요" `[검증필요]` |
| 19~22s | 정리본 PDF 스크롤 | "댓글에 '출산' 남기면 기한표 보내드려요" |

업그레이드 포인트: 벤치마크는 "얼마"만, 우리는 **"언제까지"**를 준다 → 저장 이유가 생긴다.

### S2. "아기옷 정가 주고 사면 안 되는 이유" — 18초
- 0~3s: 같은 옷 두 벌 들고 "이거 둘 다 같은 옷인데 가격이 [N]배 차이"
- 본문: 아울렛·리퍼·시즌오프 시기 캘린더 (월별 1컷)
- CTA: "'아기옷' 댓글 → 월별 세일 캘린더"
- 주의: 특정 쇼핑몰 가격 비교 시 캡처일 명시

### S3. "[연도] 바뀐 육아 지원금, 우리 집은 얼마?" — 25초
- 0~3s: 계산기 + "소득 따라 다 달라요. 30초면 계산돼요"
- 본문: 소득 구간 3개 × 받는 금액 표 (출처 캡션)
- CTA: "'계산' 댓글 → 구간표 DM"
- 리스크: 제도 변경 시 즉시 캡션 수정 + 고정 해제 규칙

## P2. 월령 체크리스트 (저장·팔로우)

### S4. "[N]개월 아기, 이건 사지 마세요" — 20초
- 0~3s: 상자째 쌓인 육아템 + "[N]개월에 산 것 중 후회하는 [3]개"
- 본문: 후회템 3개 → 각각 "대신 이걸로 충분" 대체안
- CTA: 저장 유도 + "다음 달 편 보려면 팔로우"
- 업그레이드: '사라'가 아니라 '사지 마라' → 광고 의심이 없어 신뢰가 쌓이고, 이후 공구 추천의 설득력이 올라간다

### S5. "D-30 출산가방, 진짜 쓴 것만" — 24초
- 0~3s: 가방 뒤집어 쏟기 "조리원에서 실제로 꺼낸 건 이것뿐"
- 본문: 쓴 것(초록 스티커) / 안 쓴 것(빨간 스티커) 분류
- CTA: "'가방' 댓글 → 체크리스트 PDF"

## P3. 비교·탈락 (신뢰·공구 지원)

### S6. "[품목] 5개 써보고 4개 버렸어요" — 25초
| 시간 | 화면 | 자막 |
|---|---|---|
| 0~3s | 5개 일렬 → 4개 손으로 밀어냄 | "[품목] 5개 써보고 4개 버렸어요" |
| 3~18s | 탈락 제품별 2초: 단점 1개씩 | "세척 불가 / 소음 / 무게 …" (측정·재현 가능한 단점만) |
| 18~23s | 남은 1개 사용 장면 | "남은 하나의 기준은 [기준 1줄]" |
| 23~25s | — | "제 비교표 필요하면 '비교' 댓글" |

- 탈락 제품 브랜드명 노출 시 **사실 기반 단점만** (비방·허위 비교 금지). 브랜드명 가림 처리 권장
- 공구 오픈 1~2일 전에 게시 → 공구 릴스의 사전 근거로 작동

### S7. "A vs B, 9초 정리" — 9초
- 좌우 분할, 항목 4개(가격·세척·소음·크기) 각 2초, 결론 없음 → "여러분은?" 자막
- 목적: 반복 재생·저장·댓글 토론. 벤치마크 모빌 비교(9초, 30만 재생) 구조

## P4. 실전 팁 (관계)

### S8. "약 뱉는 아기, 이렇게 해보세요" 류 — 15초
- 실제 겪은 문제 1개 → 해결 1개. CTA 없이 팔로우만
- **의학적 방법은 소아과 확인 문구 필수**. 근거 없는 효능 주장 금지

---

## P5. 공구 (전환)

### S9. 공구 오픈 — 상황 반전형 — 25초
| 시간 | 화면 | 자막 |
|---|---|---|
| 0~1s | 화면 우상단 '광고' 고정 표기 시작 | — |
| 0~3s | 엄마가 소파에 앉아 커피, 아기는 혼자 놀이 중 | "엄마가 커피 다 마실 때까지 안 울었어요" |
| 3~10s | 제품 사용 장면 3컷 (아기 반응) | 사용 상황 중심 |
| 10~16s | S6에서 비교한 탈락 제품 1컷 플래시 | "5개 중에 이걸 남긴 이유" |
| 16~22s | 가격 카드 | "정가 [  ] → 공구가 [  ] · [기간]" (정가 근거 확인) |
| 22~25s | — | "'키워드' 댓글 → 링크 DM" |

### S10. 공구 마감 리포트 — 20초
- 0~3s: "[N]분이 같이 샀어요. 후기 모아봤어요" `[실제 수치만]`
- 본문: 구매자 후기 캡처 3개(동의 받은 것만) + 불만 1개와 대응
- CTA: "앵콜 원하면 '앵콜' 댓글" → 다음 공구 수요조사 겸 리드 수집
- 업그레이드: 벤치마크는 마감 후 캡션만 교체. 우리는 **후기·불만 대응을 공개**해 다음 공구 전환율을 올린다

---

## 시나리오 운영 규칙
1. 한 영상 = 약속 1개 = CTA 1개
2. 댓글 키워드는 영상마다 다르게 → DM 자동화에서 리드 출처 추적 가능
3. 성과 상위 P1·P2는 4주 뒤 **같은 구조·다른 주제**로 재생산 (구조가 검증된 것)
