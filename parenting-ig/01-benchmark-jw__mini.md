### 데이터가 말하는 5가지

1. **댓글이 좋아요보다 많다 = 댓글이 'DM 신청서'다.** `[원리]` 지원금 릴스 댓글 29.6K / 좋아요 2.2K. 캡션에 "댓글에 '정보' 남기면 보내드려요"가 있다. 댓글 수는 반응이 아니라 **자동 DM 신청 수**로 읽어야 한다.
2. **CTA 없는 팁은 바이럴만 하고 리드는 0이다.** 약 먹이기(75K 재생)는 댓글율 0.10%. 같은 계정 안에서 CTA 유무가 댓글율을 수십 배 가른다.
3. **"돈" 정보가 가장 멀리 간다.** 상위 3개 모두 "지원금·할인·손해"를 다룬다. 육아 정보 중 **손실 회피 + 금액 명시**가 비팔로워 확산의 핵심 축이다. `[경험칙]`
4. **9초 비교 릴스는 반복 재생으로 뜬다.** 모빌 비교 306K, 댓글율 0.16%. 짧고 결론 없는 비교 → 다시 보기·저장형. 리드 수집은 약하지만 공구 직후 **지원 사격**으로 쓰였다(공구 오픈 다음 날 게시).
5. **공구 릴스 도달은 팔로워의 20~50%에 머문다.** 공구는 신규 유입 채널이 아니라 **기존 팔로워 수익화 채널**이다. 팔로워 기반 없이 공구 릴스부터 만들면 도달 자체가 안 나온다.

## 3. 공구 운영 사이클 (바이오·게시일 역산)

바이오에 3주치 공구 일정을 고지한다: `11/11~15 아기병풍 → 11/17~22 블랭킷 → 11/23~26 홈캠`

| 시점 | 콘텐츠 | 실제 사례 |
|---|---|---|
| 오픈 D-1~D0 | **상황형 소개 릴스** (문제 공감 → 실사용 → 할인율 → 댓글 키워드) | 병풍 11/10, 분유포트 10/21, 하베 11/03 |
| 오픈 중 | **지원 콘텐츠** (비교·이유 N가지·저장 유도) | 모빌 비교 11/04, 병풍 이유 5가지 11/12 |
| 마감 직후 | 같은 영상 캡션을 **#공구마감 / #공구종료**로 바꿔 상시 리드 수집 | 비데, 분유포트 10/25 |

- 공구 1회 = 4~6일, 거의 **주 1회 순환**. 팔로워는 "다음 주엔 뭐지"를 바이오에서 확인한다.
- 마감 후에도 "댓글 남기면 링크 보내드려요"를 유지 → **앵콜·상시 판매 링크로 리드 회수**. `[경험칙]`
- 외부 링크 `mkt.shopping.naver.com/link/…` = 네이버 쇼핑 커넥트 계열 제휴 추적 링크로 보인다. `[검증필요]` 판매 대행(제휴 수수료)인지 자체 판매인지는 미확인.

## 4. 제작 문법

### 4-1. 커버(첫 프레임)
- **얼굴 + 제품/소품을 카메라 앞으로** 내민 바스트 샷. 정보형은 엄마 얼굴, 공구형은 제품·아기 장면 위주.
- 2줄 대형 텍스트. 핵심 단어만 **핑크/노랑 박스 하이라이트**, 흰 글씨+검정 외곽선.
- 상단 작은 띠 문구 `"이거 다 챙기면 ○○ 아낄 수 있어요 ⚠️"` + 하단 보조 말풍선.
- 💁🏻‍♀️ 손 든 이모지 캐릭터, ✦ 반짝이 스티커 → 피드 그리드 통일감.

### 4-2. 영상 구성 (1위 릴스 23초 장면 분석)
| 구간 | 화면 | 역할 |
|---|---|---|
| 0~3s | 얼굴 등장 + 소품(임산부 뱃지) + 손가락 숫자 | 후킹: "9가지" + "모르면 손해" |
| 4~16s | **손만 등장, 탑뷰 노트 필기** + 배속, 상단 자막 초당 1개 교체 | 리스트 정보 9개 고속 전달 |
| 17~18s | 얼굴 재등장, 카드(국민행복카드) 들기 | 신뢰·전환 |
| 19~22s | 요약 자료 화면 스크롤 | CTA: "댓글에 '정보'" |

- 총 4컷. 컷 수가 아니라 **자막 교체 속도**로 템포를 만든다.
- **AI 음성(TTS) 내레이션 + 경쾌한 BGM.** 얼굴은 나오지만 목소리는 AI → 촬영 부담 최소화.

### 4-3. 캡션 공식 (공구형)
```
🚨 [상황 반전 훅 — "아기엄마가 TV 봐도 돼??"]
[공감: "~할 때 있잖아요 🥹"]
[신뢰: 내돈내산 / 다 써보고 돌고돌아 정착 / 본사에 직접 연락]
[제품명 + 할인율: "47%🔽", "정가 20만 후반 → 10만원대"]
✅ 장점 3개 (체크 이모지 리스트)
💬 '키워드' 댓글 남기면 링크 바로 보내드릴게요!
```
- 정보형은 첫 줄에 `(💌저장!)` → 저장 지표 유도.

### 4-4. 후킹 문장 은행 (원문 구조, 그대로 쓰지 말 것)
| 공식 | 원문 |
|---|---|
| 손실 회피 | "이거 진짜 모르고 지나가면 손해예요…😳" / "안 하면 진짜 돈 날려요" |
| 숫자 + 금액 | "매달 20만원" / "최대 240만원" / "50~80% 싸게" |
| 상황 반전 | "아기엄마가 아기 안 보고 TV 봐도 돼??" |
| 금지형 | "절대 당근하지 마세요" |
| 비교 | "A vs B, 뭐 살지 고민이라면" |

## 5. 왜 먹혔나 — 가설 3개

1. **"돈"으로 비팔로워를 모으고, "아기"로 신뢰를 쌓고, "할인"으로 판다.** 세 동기가 콘텐츠 유형별로 분리돼 있어 공구가 정보 계정의 신뢰를 갉아먹지 않는다.
2. **댓글 → 자동 DM 구조가 알고리즘 신호와 리드 수집을 동시에 만든다.** 댓글 폭증이 추천 노출을 키우고, DM 수신자는 계정과 대화 이력이 생겨 이후 공구 DM 도달이 높아진다. `[경험칙]`
3. **페르소나가 상품이다.** "파워 J 엄마가 비교해서 골랐다"는 위임 심리. 실제 아기(초롱이) 월령에 맞춰 상품이 바뀐다(4개월 → 모빌·병풍·약 먹이기). 월령 동기화가 곧 상품 기획이다.
