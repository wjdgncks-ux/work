숏폼 편집기 설치 안내

Windows 10·11 기준 · PC마다 처음 한 번 · 순서대로 따라 하면 됩니다

인터넷여유 공간 15GB 이상NVIDIA 그래픽카드 권장받은 파일 shortform-editor.zip
1

Python 설치

편집기를 돌리는 기본 프로그램
  1. python.org/downloads/windows 에서 Python 3.13.x의 Windows installer (64-bit) 받기
  2. 설치 첫 화면 맨 아래 Add python.exe to PATH 체크 → Install Now
  3. "Setup was successful"이 나오면 닫기
2

편집기 파일 풀기

폴더 위치가 중요
  1. 받은 shortform-editor.zip 우클릭 → 모두 압축 풀기
  2. 풀 위치를 C:\ 로 지정 → C:\shortform-editor 폴더가 생김
  3. 바탕화면·문서 폴더는 피하기(OneDrive 동기화 때문에 설치 오류가 날 수 있음)
3

편집기 설치

자동 진행 · 창을 닫지 말 것
  1. 폴더 안 install-windows.bat 더블클릭
  2. 파란 창 "Windows의 PC 보호"가 뜨면 추가 정보 → 실행
  3. "ffmpeg 설치가 끝났으면… 한 번 더 더블클릭" 이 나오면 창을 닫고 한 번 더 더블클릭
  4. "설치가 끝났습니다" 가 보이면 아무 키나 눌러 닫기
4

AI 음성 앱 VoiceStudio 설치

무료 · 첫 실행이 가장 오래 걸림
  1. github.com/debpalash/VoiceStudio/releases 에서 이름이 …-win-x64.exe 로 끝나는 파일 받아 설치
  2. 첫 실행 때 필요한 구성요소를 스스로 내려받음 → 끝날 때까지 기다리기
  3. Settings → Models → TTS → VoxCPM2 설치 → 라이선스 Accept
  4. Settings → Models → ASR → Whisper 하나 설치(나레이션 자막 타이밍용)
OmniVoice(VoiceStudio TTS)는 비상업용 모델입니다. 회사·광고·수익 채널 영상에는 VoxCPM2를 씁니다.
5

첫 실행 · 점검

설정은 한 번만
  1. start-windows.bat 우클릭 → 보내기 → 바탕 화면에 바로 가기 만들기
  2. 바로가기 실행 → 브라우저에 시작 화면이 열림
  3. 왼쪽 설정·점검 → 작업자 이름 입력 → 저장
  4. 점검 목록이 ✓ 인지 확인. AI 음성 줄: "연결됨 · VoxCPM2"
6

매일 쓰는 순서

설치 후에는 이것만
  1. VoiceStudio를 먼저 켜기(AI 음성을 쓸 때)
  2. 바탕화면 숏폼 편집기 바로가기 실행
  3. 검은 창은 닫지 않기(닫으면 편집기가 꺼짐, 작은 창으로 내려 두기)
  4. 영상을 끌어다 놓기 → 채널·영상 종류 고르기 → 자동 편집 시작
  5. 시작 화면에 새 버전 알림이 뜨면 지금 업데이트 (자동으로 다시 열림)

이럴 때는

"Python이 없습니다"1번을 다시. PATH 체크를 확인하고 PC를 재시작한 뒤 3번
설치 창에 "실패"가 뜨고 멈춤인터넷 연결 확인 후 install-windows.bat 다시 실행
'음성' 탭 "VoiceStudio가 꺼져 있습니다"VoiceStudio 실행 → 편집기에서 다시 연결
"엔진이 설치되지 않았습니다" · "라이선스를 수락하세요"4번의 TTS → VoxCPM2 설치·Accept
자막이 나레이션과 조금 어긋남4번의 ASR → Whisper 설치
화면이 안 열림검은 창의 글을 사진으로 찍어 담당자에게

Mac을 쓴다면

  • M1~M4 칩 Mac만 AI 음성 가능(Intel Mac은 불가)
  • 설치 install-mac.command, 실행 start-mac.command. 처음엔 우클릭 → 열기
  • VoiceStudio는 …-mac-arm64.dmg

꼭 지킬 것

  • 다른 사람 목소리 복제는 본인 동의를 받은 뒤에만
  • AI 음성 영상의 'AI 음성' 표시를 끄지 않기
