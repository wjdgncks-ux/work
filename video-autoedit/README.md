# video-autoedit — SNS 숏폼 자동 편집기

원본 영상을 넣으면 **분석 → 기획 → 진단 → 렌더링**을 자동으로 수행해 Reels/Shorts/TikTok용 세로 영상과
편집 리포트(진단표·업로드 패키지·검수 체크리스트)를 만든다.

```
원본.mp4 ─▶ analyze ─▶ planner(Claude | 규칙) ─▶ pacing(보정) ─▶ scorecard(진단·자동수정) ─▶ render(ffmpeg)
            무음/음량피크/장면전환/       후킹·컷·강조·효과음·         단어경계 스냅·정지구간    3초룰·컷리듬·자막·CTA·      9:16 리프레이밍·줌펀치·
            대표프레임/음성인식          자료화면·캡션 기획           줌 보충·과밀 제거         규정·사실검증 플래그        자막·효과음·BGM덕킹·-14LUFS
```

## 설치·실행 (일반 사용자용)

이 프로그램은 **각자 PC에 설치해서 쓰는 방식**이다. 영상은 PC 밖으로 나가지 않는다.
외부로 나가는 것은 선택 기능뿐이다: Claude(편집 기획·대본)에 보내는 글. AI 음성·내 목소리는 같은 PC의 VoiceStudio 앱이 만든다(밖으로 안 나감).

**받는 방법**: 담당자가 보낸 `shortform-editor.zip`을 `C:\`에 풀거나, GitHub에서
[이 브랜치 ZIP](https://github.com/wjdgncks-ux/work/archive/refs/heads/claude/kind-pascal-w0102p.zip)을 받아 그 안의
`video-autoedit` 폴더를 쓴다. **인쇄용 설치 안내문(A4 한 장)**: `install-guide.pdf` (원본 `docs/install-guide.src.html`,
다시 만들기 `python docs/build_install_guide.py`).

| | Windows | Mac |
|---|---|---|
| 1. 준비 | python.org에서 Python 설치(첫 화면 **Add python.exe to PATH** 체크) | brew.sh에서 Homebrew 설치 |
| 2. 설치(처음 한 번) | `install-windows.bat` 더블클릭 (ffmpeg를 프로그램 폴더 `tools\ffmpeg`에 자동으로 받음, 약 200MB) | `install-mac.command` 더블클릭(처음엔 우클릭 → 열기) |
| 3. 실행 | `start-windows.bat` 더블클릭 → 바탕화면 바로가기 권장 | `start-mac.command` 더블클릭 |
| 4. AI 음성(선택) | [VoiceStudio 내려받기](https://github.com/debpalash/VoiceStudio/releases/latest)(`.exe`) → 실행 → '모델'에서 **VoxCPM2** 설치·라이선스 수락 | 같은 곳에서 `.dmg`(Apple Silicon만 가능, Intel Mac 불가) |

실행하면 브라우저에 **시작 화면**이 열린다. 아이콘을 두 번 눌러도 창만 다시 열린다(중복 실행 방지).
설치 문제가 있으면 시작 화면 맨 위에 빨간 안내가 뜨고, '설정·점검'에 해결 방법이 나온다(`python -m autoedit doctor`와 같은 점검).

### 시작 화면 (`python -m autoedit app`)
- **새 프로젝트**: 영상을 끌어다 놓기 → 채널(회사/내/와이프) → 영상 종류(설명형/유머/시연) → 올릴 곳 → **자동 편집 시작**
  → 진행률을 보여 주고, 끝나면 편집기가 자동으로 열린다.
- **Reels·Shorts·TikTok을 같이 고르면 프로젝트는 하나**: 한 번 편집하고, 내보낼 때 플랫폼별 파일을 만든다
  (자막·문구 위치만 각 플랫폼 화면에 맞춤, 컷 인코딩은 한 번만). 가로 YouTube는 별도 프로젝트.
- **최근 프로젝트**: 표지·채널·플랫폼·컨펌 상태·버전. 채널별·상태별로 거르고, 카드에서 상태 변경·폴더 열기
- **설정·점검**: 작업자 이름(검수표 '제작'), 작업 폴더(기본: 문서/숏폼편집), 자동 캡션 정확도, AI 음성 엔진(VoiceStudio), Claude 키, 설치 점검

### 업데이트 (프로그램 안에서)
- 시작 화면에 **새 버전** 알림(바뀐 점 포함)이 뜨면 **지금 업데이트** → 내려받기·교체 → 프로그램이 자동으로 다시 열린다.
- **설정·점검 → 업데이트**: 새 버전 확인, **파일로 업데이트**(담당자가 보낸 `shortform-editor.zip`), **이전 버전으로 되돌리기**.
- 바뀌는 것은 프로그램 파일뿐이다. 작업 폴더·프로젝트·설정·내 목소리·`assets` 안 사용자 자료·`.venv`는 그대로.
  바뀌기 전 파일은 `~/.autoedit/updates/backup`에 보관(직전 1회분).
- 안전장치: 자동 편집·내보내기 중에는 업데이트를 막는다. 구성요소(`requirements.txt`)가 바뀌면 앱이 꺼진 사이에 설치한다
  (윈도우는 쓰는 중인 파일을 못 바꿈). **새 버전이 시작되지 않으면 자동으로 이전 버전으로 되돌리고** 알림을 띄운다.
- 구조: `start-*.bat/.command` → 실행기(`autoedit/launcher.py`, 계속 살아 있음) → 앱(업데이트 뒤 종료 코드 75로 끝나면 다시 띄움).
  실행 스크립트는 통째로 읽어 실행하게 만들어, 업데이트가 실행 중인 스크립트를 바꿔도 깨지지 않는다.
- 출처: `version.json`의 `update`(GitHub 저장소·브랜치·폴더). 버전 확인은 1시간에 한 번. 저장소를 비공개로 바꾸면 설정에 GitHub 키 입력.
- **새 버전을 내보내는 법(관리자)**: 코드 수정 → `version.json`의 `version`을 올리고 `notes`에 바뀐 점 → 커밋·푸시. 끝.
- 개발 폴더(git)에서는 앱 업데이트를 쓰지 않는다(git pull).
- 1.0(첫 ZIP)에는 업데이트 기능이 없으므로, 그 ZIP으로 설치한 PC는 새 ZIP으로 한 번만 다시 설치한다.

### 컨펌(제작자 ≠ 컨펌자, 완성본으로 소통)
1. 편집기 **내보내기** → `v1`, `v2`… 로 새 파일이 쌓인다(이전 버전은 남음). 기본으로 '컨펌 요청' 상태가 된다.
2. 함께 만들어지는 **검수표_vN.html**(표지·체크리스트·업로드 문구·자동 점검·협찬/AI 표시)과 완성본 mp4를 메신저로 보낸다.
   검수표는 휴대폰에서도 열린다.
3. 컨펌자가 "0:12 자막 오타"처럼 보내면 편집기 **수정 요청** 탭에 그대로 붙여 넣는다 → 시간을 누르면 그 장면으로 이동, 반영한 줄은 체크.
4. 다 고치면 다시 내보내기(v2). 상태: 편집 중 → 컨펌 요청 → 수정 요청 → 승인 → 업로드 완료.
- 편집 내용은 자동 저장되고 1분 단위로 자동 백업된다(**버전** 탭 → 이 시점으로 되돌리기).

### 개발자용 설치

```bash
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m autoedit doctor
```

## 사용법

```bash
# 1) 채널 프로필로 자동 편집 (profiles/company.json · me.json · wife.json)
python -m autoedit run 촬영1.mp4 촬영2.mp4 --profile company

# 2) 장르(스타일) 직접 지정: explainer=설명형, funny=유머·재미, demo=제품 시연
python -m autoedit run 브이로그.mp4 --profile wife --style funny

# 3) 수작업 편집기(브라우저) — 자동 편집 결과를 열어 직접 다듬고 렌더링
python -m autoedit edit out/company/촬영1/reels

# 기타
python -m autoedit run a.mp4 --plan-only              # 기획서·리포트만
python -m autoedit render out/me/a/reels/plan.json    # plan.json을 직접 고친 뒤 렌더링(--preview 저화질)
python -m autoedit profiles                           # 프로필 목록
```

출력: `out/<프로필>/<영상>/<플랫폼>/` 아래 `<영상>_<플랫폼>.mp4`, `.cover.jpg`, `report.md`, `plan.json`.

### 스타일(장르)별 차이 — `autoedit/styles.py`

| | 설명형 `explainer` | 유머 `funny` | 제품 시연 `demo` |
|---|---|---|---|
| 후킹 | 질문·숫자·반전 문장 | 가장 큰 리액션(음량 피크) 미리보기 | 결과·완성 장면 미리보기 |
| 무음 컷 | 0.35초↑ 전부 컷(속도감) | 0.8초↑만 컷(펀치라인 앞 '숨' 유지) | 0.6초↑ 컷 + 말 없는 작업 구간 2~4배속 |
| 강조 | 핵심 단어 줌 | 강한 줌 + 플래시 + boing | 약한 줌, STEP 단계 카드 |
| 효과음 | whoosh/pop/ding/boom | whoosh/boing/riser | whoosh/pop/ding/riser |
| 길이 | 플랫폼 권장 | 권장 × 0.8 | 권장 × 1.2 |

### 채널 프로필 — `profiles/*.json`

채널별로 기본 장르·플랫폼·CTA·고정 해시태그·자막 강조색·핸들 워터마크·자료 폴더를 저장한다.
`[ ]` 표시 칸과 `@계정`을 실제 값으로 바꿔 쓰고, 자료 이미지는 `assets/<채널>/`에 넣는다(파일명이 대사 키워드와 맞으면 자동 삽입).
명령행 옵션이 프로필보다 우선한다.

### 수작업 편집기 — CapCut과 같은 화면·조작 (`python -m autoedit edit <프로젝트 폴더>`)

브라우저(127.0.0.1)에서 열린다. 설치할 것 없음(파이썬 표준 라이브러리). CapCut PC판 배치를 그대로 따랐다.

```
┌ 소재 패널 ─────────┬──── 플레이어 ────┬─ 속성 ─┐   상단 오른쪽: [AI 진단 점수] [내보내기]
│미디어 오디오 텍스트 │  완성본 미리보기  │ 비디오 │
│자료 효과 전환 캡션 │ (자막·텍스트·줌·  │ 속도   │
│AI 편집             │  효과음 반영)     │ 텍스트 │
├────────────────────┴─────────────────┴────────┤
│ ↶ ↷ │ 분할 왼쪽삭제 오른쪽삭제 삭제 │ 복제   …  자석 ─●─ 확대 │
│ 효과 / 텍스트 / 캡션 / 자료 / [메인 영상 트랙] / 효과음        │
└──────────────────────────────────────────────────┘
```

- **편집기를 처음 열면 자동 무음 컷이 실제 클립으로 나뉜다** → 타임라인에 보이는 그대로 내보내진다.
- 클립: 클릭 선택, 끌어서 순서 변경(자석), 양 끝을 끌어 길이 조절, 오른쪽 패널에서 역할·배속
- 텍스트·자료·효과·효과음: 왼쪽 패널에서 ＋(재생 헤드 위치에 추가) → 타임라인에서 끌어 이동, 오른쪽 끝을 끌어 길이 조절
- 캡션: 왼쪽 '캡션' 탭에서 오타 수정 → 적용, 또는 타임라인 캡션 블록 선택 후 오른쪽에서 수정
- AI 편집 탭: 스타일 선택 → **AI 재편집**(Ctrl+Z로 되돌리기 가능), AI 진단 이슈 목록
- 미디어/자료 **가져오기**: 영상·이미지를 바로 추가(영상은 자동 캡션까지 분석)
- 자동 저장, 내보내기 창에서 최종(1080p)/빠른 미리보기 선택 → 결과 확인·다운로드
- 원본이 HEVC(아이폰 기본)·4K면 편집용 H.264 사본을 자동 생성(내보내기는 원본 화질)

| 단축키(CapCut 기본값과 동일) | 동작 |
|---|---|
| `Space` | 재생/정지 |
| `Ctrl+B` | 재생 헤드에서 분할 |
| `Q` / `W` | 왼쪽 삭제 / 오른쪽 삭제 |
| `Delete` | 선택 항목 삭제 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 실행 취소 / 다시 실행 |
| `←` `→` (`Shift`) | 1프레임(1초) 이동 |
| `↑` `↓` | 이전/다음 편집 지점 |
| `Ctrl+=` `Ctrl+-` · `Ctrl+휠` · `Shift+Z` | 타임라인 확대·축소·맞춤 |
| `Ctrl+D` | 복제 |
| `Ctrl+E` | 내보내기 |

CapCut과 다른 점(아직 없음): 화면 전환 효과(디졸브 등), 필터·색보정, 키프레임 애니메이션, 텍스트 글꼴·위치 자유 배치
(텍스트 위치·크기는 플랫폼 안전영역 기준으로 자동). 텍스트·효과는 영상 내용에 붙어 있어서 클립을 옮기면 같이 움직인다.

### 레퍼런스 스타일 — "이 영상처럼 편집해 줘"
새 프로젝트 창의 **레퍼런스 스타일**에서 따라 하고 싶은 영상을 넣으면 **스타일 카드**를 만들어 편집에 반영한다.

| 분석 항목 | 방법 | 반영되는 곳 |
|---|---|---|
| 컷 리듬(평균 컷 길이·첫 전환·10초당 컷) | 화면 전환 감지(점프컷용으로 민감하게) | 줌·컷 간격 |
| 남겨 둔 쉼·말 속도·소리 강조 빈도 | 무음·음성 인식·음량 | 무음 컷 기준 |
| 후킹 형식·말투·문장 스타일·CTA·제목 형식 | Claude가 대사·대표 장면을 보고 **형식만** 정리(내용 자리는 ○○) | AI 기획(후킹 문구·카드·CTA·제목·캡션), AI 대본 |
| 자막 모양(위치·크기·글자색·강조색·배경·한 줄 글자 수) | Claude가 대표 장면에서 판단 | 자막 렌더링, 편집기 미리보기 |

- 넣는 법: **영상 파일 올리기(권장)** 또는 링크. 링크는 내 채널·사용 허락을 받은 영상만(확인 체크 필수). 플랫폼 약관상
  무단 다운로드는 금지이고, 인스타그램은 로그인 문제로 자주 실패한다.
- **같은 크리에이터 영상 3~5개**를 권장한다. 1개면 그 영상만의 우연한 특징이 섞인다고 카드에 경고가 뜬다.
- Claude 키가 없으면 컷 리듬·쉼만 반영된다(문구·톤·자막 모양은 분석 안 됨). 컷이 감지되지 않으면 컷 길이는 반영하지 않는다.
- 레퍼런스의 **문장·음악은 가져오지 않는다**(표절·저작권). 장르 기준·규정(최상급·효능 단정 금지)·사실 검증이 레퍼런스보다 우선.
- 편집기 오른쪽 **스타일** 탭: 카드 확인·수정(자막 모양은 미리보기에 바로 반영), 다른 카드로 바꾸기, **이 스타일로 다시 편집**.
- **이 채널의 기본 스타일로 저장**하면 그 채널의 다음 프로젝트에 자동 적용(새 프로젝트 창에서 '사용 안 함'으로 끌 수 있음).
- 카드는 `~/.autoedit/styles`, 레퍼런스 영상은 작업 폴더의 `레퍼런스`. 검수표에 사용한 레퍼런스 스타일이 표시된다.
- 명령행: `python -m autoedit reference add r1.mp4 r2.mp4 --name "와이프 톤" --channel wife`, `reference list`,
  `run … --reference <id|none>`

**군말 자동 제거**: "음·어·으" 등은 항상, "그·저·뭐·막·이제"는 앞뒤로 쉬어 따로 떨어져 있거나 문장 전체가 군말일 때만
자막에서 빼고 컷한다("그 사람"의 '그'는 남김).

**진단 점수는 편집 구조의 결함을 보는 점수이고, 조회수 예측이 아니다.** 소재의 매력, 타겟 적합성, 차별점은 리포트 6번 체크리스트로 사람이 판단한다.

## 테스트·사용성 하네스

```bash
python -m pytest -q tests                          # 단위·통합(렌더링 포함) 46개
AUTOEDIT_SKIP_RENDER=1 python -m pytest -q tests   # 렌더링 제외(빠름)
cd tests/e2e && npm install && cd ../.. && bash tests/e2e/run.sh   # 사용성 E2E → e2e-report/report.md
```

**사용성 E2E 하네스**(`tests/e2e/`)는 실제 앱을 가짜 VoiceStudio 서버(실제와 같은 API, `tests/fake_voicestudio.py`)·가짜 음성 인식으로 띄우고, 한글·공백·작은따옴표가 든 파일
이름의 영상으로 *시작 화면 → 업로드 → 자동 편집 → 편집기(분할·되돌리기·나레이션·텍스트) → 최종 내보내기 → 검수표 →
수정 요청 → 홈 카드 → 설정* 을 **노트북(1366×768)과 FHD(1920×1080)** 에서 따라간다. 검사 항목:
콘솔·요청 오류, 가로 넘침, 핵심 버튼이 화면 안에 보이는지, 플레이어·타임라인 최소 크기, 입력 중 단축키 오작동,
자동 저장, 진행률 표시, 단계별 소요 시간. 결과는 `e2e-report/report.md`와 단계별 스크린샷.
